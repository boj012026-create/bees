# Node express testing
Picked Bee theme to separate optional variables etc from mandatory syntax.  
Endpoints returns what you send in json-format
## Endpoints
bees/wings/randomID/randomName  
bees/?your=queries&comes=here

## Quick start
- download and install if you don't already have it [node](https://nodejs.org/en/download)
- run following commands 
```shell
npm install
npm run dev
```
## Example input for url bar
```
http://localhost:3002/bees/wing/102/dave
```
```
http://localhost:3002//bees/?smell=rose&age=34 
```
